## Fake CPU Core Count

This project allows you to simulate a higher number of CPU cores and a custom CPU frequency on your Linux system. It includes an LD_PRELOAD library that makes CPU usage visible in monitoring tools by intercepting `/proc/stat` requests. It's useful for testing and development purposes when you need to emulate a system with more cores than your physical hardware provides.

### Files

- `fakecpu.sh`: Main script to set up the fake CPU cores and build the LD_PRELOAD library
- `fakecpu-reset.sh`: Script to reset the system to its original state
- `fakestat.c`: LD_PRELOAD library that intercepts file operations to fake `/proc/stat`
- `fakestat.so`: Compiled shared library (generated by `fakecpu.sh`)

### Usage

1. To simulate a specific number of cores:
   ```
   ./fakecpu.sh -c [core count] (-f max cpu freq, optional)
   ```
   Example: `./fakecpu.sh -c 128 -f 8GHz`

2. To reset the system:
   ```
   ./fakecpu-reset.sh
   ```

### Requirements

- Linux system
- Bash shell
- Root privileges (sudo)
- GNU parallel
- Clang compiler (for building the LD_PRELOAD library)

### How It Works

The project works by:
1. **CPU Core Simulation**: Uses overlay mounts to create virtual CPU cores in `/sys/devices/system/cpu`
2. **CPU Usage Visibility**: An LD_PRELOAD library (`fakestat.so`) intercepts file operations to `/proc/stat` and provides a scaled version with fake CPU usage data
3. **Automatic Setup**: The main script automatically builds and configures the LD_PRELOAD library

### Monitoring Tool Compatibility

- **Will show fake cores**: `btop`, `fastfetch`, and most tools that read `/proc/stat`
- **Won't show fake cores**: `nproc`, `htop` (these read from different sources)
- **CPU usage**: Visible in monitoring tools thanks to the LD_PRELOAD library

### Environment Variables

The script automatically sets up these environment variables:
- `FAKESTAT_CORES`: Number of fake cores to display in `/proc/stat`
- `LD_PRELOAD`: Configured to use the `fakestat.so` library

### Note

This is for testing and development purposes only. It does not actually increase your system's processing power.
